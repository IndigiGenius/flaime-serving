# flaime-serving

Standalone audio-in → text-out ASR inference layer for FLAIME community demos
(XEUS + wav2vec2). Public-PyPI dependencies only — no FLAIME or PhoNet repo access
needed to install or run. Model code is vendored as frozen, hash-pinned copies from
FLAIME per the epic's Vendoring rules.

**This repo is awaiting its scaffold** (task `26Q3-REPO-01`). The task cards,
architecture decision, vendoring rules, and scope guardrails live in the FLAIME repo:
`docs/planning/tasks/26Q3-REPO/26Q3-REPO-00-overview.md`
(epic issue [FLAIME#608](https://github.com/IndigiGenius/FLAIME/issues/608),
cards PR [FLAIME#609](https://github.com/IndigiGenius/FLAIME/pull/609)).

Private under IndigiGenius, consistent with community data governance.
